# 13 — Before / After Comparison

## When to use
Use at the Inciting Incident for instant contradiction or at Climax to close with visual proof. The images must be aligned.

Hook: same-pixel comparison makes change undeniable and lets the reader perform the proof.

## When NOT to use
Do not compare mismatched scales, seasons, or camera angles; the slider will imply false precision.

## Prompt
Layer two canvases, clip the top layer by percentage, and move a divider/handle together. Support pointer dragging and arrow keys on the handle.

## Implementation
```js
let baPos = 50, baAnim = null, baDrag = false;
function setBA(p) {
  baPos = Math.max(0, Math.min(100, p));
  baClip.style.width = baPos + '%';
  baDiv.style.left = baPos + '%';
  baHandle.setAttribute('aria-valuenow', Math.round(baPos));
  baStat.innerHTML = `Surface water loss: <b>${Math.round((100 - baPos) * 0.58)}%</b> revealed`;
}
baWrap.addEventListener('pointerdown', e => {
  baDrag = true; if (baAnim) cancelAnimationFrame(baAnim);
  setBA(baFromEvent(e)); baWrap.setPointerCapture(e.pointerId);
});
baWrap.addEventListener('pointermove', e => { if (baDrag) setBA(baFromEvent(e)); });
baHandle.addEventListener('keydown', e => {
  if (e.key === 'ArrowLeft') { setBA(baPos - 4); e.preventDefault(); }
  if (e.key === 'ArrowRight') { setBA(baPos + 4); e.preventDefault(); }
});
```

## Known failure
Keyboard parity was missing until the handle became an arrow-key slider.
