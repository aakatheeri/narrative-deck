# 12 — AR Placeholder — Spatial Artifact Viewer

## When to use
Use at the Midpoint when spatial inspection rewards reader agency. It approximates AR while keeping the artifact usable in plain canvas.

Hook: embodied control makes form and scale feel discovered, not merely described.

## When NOT to use
Do not put required facts only behind tilt sensors; permission and hardware can fail.

## Prompt
Project object-space points through yaw and pitch, draw a rotating artifact, expose hotspots as buttons, and gate deviceorientation behind a user gesture. Drag remains the baseline control.

## Implementation
```js
const SPOTS = [{ yaw:0, y:-40, label:'Rim chip', desc:'A clean fracture.' }];
let arYaw = 0, arPitch = 0;
function project(x, y, z) {
  const cy = Math.cos(arYaw), sy = Math.sin(arYaw);
  const cp = Math.cos(arPitch), sp = Math.sin(arPitch);
  let x1 = x * cy - z * sy;
  let z1 = x * sy + z * cy;
  let y1 = y * cp - z1 * sp;
  let z2 = y * sp + z1 * cp;
  const f = 620 / (620 + z2);
  return { x: AR_W / 2 + x1 * f, y: AR_H / 2 + y1 * f, f, z: z2 };
}
arTilt.addEventListener('click', async () => {
  const DOE = window.DeviceOrientationEvent;
  if (DOE && typeof DOE.requestPermission === 'function') {
    const res = await DOE.requestPermission(); if (res !== 'granted') return;
  }
  addEventListener('deviceorientation', onTilt);
});
```

## Known failure
Sensor permission must be requested from a click; automatic tilt setup fails on iOS.
