# 15 — Dynamic Paywall Simulator

## When to use
Use at Resolution when the story turns into an ask, constraint, or model decision. It makes the interruption inspectable after value is established.

## When NOT to use
Never place before the reader understands the value exchange; it becomes obstruction, not narrative.

## Prompt
Model free-article limit and propensity from range inputs, render cells as free/edge/locked, and replay three archetypes with timeouts. Clear pending sweeps on manual input.

## Implementation
```js
function pwModel(eng, freq, price) {
  const base = 10;
  const limit = Math.round(base - eng * 0.72 - freq * 0.34 + price * 0.85);
  const clamped = Math.max(2, Math.min(PW_MAX, limit));
  const propensity = Math.max(2, Math.min(97, Math.round(eng * 6.4 + freq * 2.9 - price * 4.1 + 18)));
  return { limit: clamped, propensity };
}
function pwRender() {
  const eng = +pwEng.value, freq = +pwFreq.value, price = +pwPrice.value;
  const { limit, propensity } = pwModel(eng, freq, price);
  pwLimit.textContent = limit; pwProp.textContent = propensity + '%';
  pwCells.forEach((c, i) => {
    const n = i + 1;
    c.classList.toggle('free', n < limit);
    c.classList.toggle('edge', n === limit);
    c.classList.toggle('locked', n > limit);
  });
}
[pwEng, pwFreq, pwPrice].forEach(input => input.addEventListener('input', () => { if (pwSweep) clearTimeout(pwSweep); pwRender(); }));
```

## Known failure
Manual slider input must clear the replay timeout or archetype sweeps overwrite the user.
